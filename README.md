# semestralniprace
Na displeji se uživateli zobrazuje uprostřed jedno červené tlačítko, které při spuštění ho vyhodí na random stránce (podobný princip jako Bored button). Okolo tlačitka budou různé emoji. Každý z nich přesměruje uživatele někam jinam. 

Music note: moje oblíbené intreprety a jejich písničky
Nákupní košík: můj wishlist
Korálek: tutoriály s korálky
Jídlo: generátor jídla
